# 🚀 Placement Pilot

### Your Placement Preparation Navigator

> **From Guesswork to Great Work**

Placement Pilot is a comprehensive placement preparation platform designed to help students navigate the campus recruitment process with confidence. By centralizing interview experiences, company insights, eligibility checks, and peer discussions, the platform transforms fragmented placement preparation into a structured and data-driven journey.

---

## 📖 Overview

Preparing for placements often involves searching through scattered resources, relying on inconsistent advice, and manually tracking progress.

**Placement Pilot** solves this problem by providing a centralized platform where students can access verified placement insights, prepare strategically, and collaborate with peers—all in one place.

---

## 🎯 Problem Statement

Current placement preparation faces several challenges:

* Information is scattered across WhatsApp groups, PDFs, and personal notes.
* Students lack access to structured company-specific preparation material.
* Interview experiences are difficult to discover and verify.
* Eligibility criteria vary across companies and are often confusing.
* Training and Placement Officers (TPOs) depend on manual tracking systems.

These issues create uncertainty and inefficiency during the placement season.

---

## 💡 Solution

Placement Pilot provides a unified ecosystem that enables students to:

* Access verified interview experiences.
* Explore company-specific preparation resources.
* Instantly check placement eligibility.
* Track their preparation journey.
* Interact with peers and seniors for guidance.

The platform bridges the gap between preparation and opportunity by making placement-related information accessible, organized, and actionable.

---

## ✨ Key Features

### 📊 Verified Interview Experiences

* Real interview experiences submitted by students.
* Structured information based on interview rounds.
* Company-wise and role-wise categorization.
* Outcome and preparation insights included.

### 🔍 Smart Company Search

* Search by company, role, or technology stack.
* Discover frequently asked interview questions.
* Access preparation tips and previous experiences.

### ✅ Eligibility Checker

* Evaluate eligibility using:

  * CGPA
  * Branch
  * Skills
  * Academic criteria
* Focus preparation on relevant opportunities.

### 📈 Personalized Dashboard

* Customized content recommendations.
* Track preparation progress.
* View relevant opportunities and discussions.
* Monitor engagement and activity.

### 💬 PrepTalk – Peer Discussion Platform

* Real-time student discussions.
* Company-specific preparation channels.
* Doubt-solving and mentorship opportunities.
* Knowledge sharing among peers and seniors.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/placement-pilot.git
cd placement-pilot
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file and add:

```env
SUPABASE_URL=your_supabase_url
SUPABASE_KEY=your_supabase_key
```

### Start Development Server

```bash
npm run dev
```
